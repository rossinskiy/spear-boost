# Spear Boost

A server-side Fabric mod for Minecraft 1.21.11. Spears enchanted with **Lunge** cost no durability and cause no hunger or exhaustion when lunging.

Players do not need to install anything. Put the jar on the server only.

## Requirements

- Minecraft 1.21.11
- Fabric Loader 0.19.0 or newer
- Java 21

## Installation

Drop `spearboost-<version>.jar` into the server's `mods` folder and restart.

## Building

```
gradlew build
```

The jar is written to `build/libs/`.
